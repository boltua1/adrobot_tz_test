# Keitaro Campaign Manager & Flow Editor (AdRobot TZ)

Веб-приложение интеграции с рекламным трекером **Keitaro Tracker** для автоматизированного создания кампаний и гибкого визуального редактирования офферов в потоках.

Репозиторий проекта: [https://github.com/boltua1/adrobot_tz_test](https://github.com/boltua1/adrobot_tz_test)

---

## 🛠 Стек технологий

- **Backend:** Python 3.11+, **FastAPI**, **SQLAlchemy 2.0 (async)**, **Alembic**, **aiosqlite**, **HTTPX**, **Pydantic v2**.
- **Frontend:** Современный адаптивный UI на **Tailwind CSS**, **HTML5**, **JavaScript**, **FontAwesome**.
- **Тестирование:** **Pytest**, **pytest-asyncio**, **pytest-mock**.
- **API:** Keitaro REST Admin API v1.

## 📋 Реализованный функционал

### Часть 1. «Создаватор» кампаний (New Campaign)
* **Входные параметры:**
  * `Name`: Имя кампании (генерирует уникальный alias для Keitaro).
  * `Geo`: Коды стран через запятую (например, `AU, MX, RO`).
  * `Offer`: Поиск оффера с **автокомплитом** по базе Keitaro API.
  * `Domain`, `Group`, `Traffic Source`: Автоматическая подгрузка доступных ресурсов из API с возможностью выбора.
* **Логика создания кампании:**
  1. Создается кампания в Keitaro с привязкой домена, группы и источника.
  2. **Поток 1 (Flow 1 / Redirect):** перехватывает посетителей из указанных стран (фильтр `country: accept [GEO]`) и делает редирект на `https://google.com`.
  3. **Поток 2 (Flow 2 / Offers):** перенаправляет остальных посетителей на выбранный оффер (`schema: landings`, `share: 100%`).
  4. Данные кампании и потоков сохраняются в локальную базу данных SQLAlchemy.

### Часть 2. «Редактор существующей кампании» (Stream & Offer Editor)
* **Синхронизация (`Fetch streams`):**
  * Загружает актуальные потоки и офферы из Keitaro API.
  * Сервисные потоки (редиректы на Google) отображаются информативно без избыточного парсинга.
  * Если оффер был удален напрямую в Keitaro, в системе он мягко помечается как `removed` (серый цвет, доля 0%, кнопка `Bring back`).
* **Добавление оффера в поток:**
  * Инпут с автокомплитом по офферам Keitaro.
  * Автоматический **равномерный пересчет весов** (например, 2 оффера по 50% → 3 оффера по 34%/33%/33% с суммой ровно 100%).
  * Поток окрашивается в **жёлтый цвет** (статус *Unpublished / Не опубликовано*).
* **Публикация изменений (`Push to Keitaro`):**
  * Отправляет активные офферы и рассчитанные доли в Keitaro API (`PUT /streams/{id}`).
  * Поток возвращается в исходный **белый цвет** (статус *Published / Синхронизировано*).
* **Отмена изменений (`Cancel`):**
  * Отменяет добавленные до публикации офферы и восстанавливает чистое состояние из Keitaro.
* **Удаление оффера (`Remove`):**
  * Оффер не удаляется из истории безвозвратно: он становится **серым** со статусом архива, его вес становится **0%**, а остальные активные офферы делят 100%.
  * Поток переходит в жёлтый статус (требует публикации).
* **Восстановление оффера (`Bring back`):**
  * Возвращает удаленный оффер обратно в активный список, пересчитывает доли.
* **Закрепление весов (`Pinning` / Запинить вес):**
  * Кнопка закрепления (булавка 📌) позволяет зафиксировать вес оффера (например, 25%).
  * При последующих операциях (добавление, удаление, возврат) закрепленный вес **не меняется**, а оставшиеся проценты распределяются между незакрепленными активными офферами.

## 🚀 Инструкция по установке и запуску

### Быстрый запуск на Windows (в 1 клик):
В корне проекта созданы готовые скрипты:
* **`start.bat`** — автоматически проверит/создаст виртуальное окружение `venv`, установит зависимости, применит миграции Alembic, запустит веб-сервер и откроет страницу в браузере.
* **`stop.bat`** — корректно остановит работающий веб-сервер на порту 8000.

---

### Ручной запуск:

#### 1. Клонирование репозитория
```bash
git clone https://github.com/boltua1/adrobot_tz_test.git
cd adrobot_tz_test
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv

# На Windows:
venv\Scripts\activate

# На Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка файла переменных окружения (`.env`)
Скопируйте пример файла конфигурации:
```bash
# Windows (PowerShell)
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Содержимое `.env`:
```ini
KEITARO_API_URL=https://*******************/admin_api/v1
KEITARO_API_KEY=********************************
KEITARO_DEFAULT_DOMAIN_ID=1813
KEITARO_DEFAULT_GROUP_ID=10332
KEITARO_DEFAULT_TRAFFIC_SOURCE_ID=836
DATABASE_URL=sqlite+aiosqlite:///./adrobot.db
APP_PORT=8000
```

### 5. Применение миграций базы данных (Alembic)
```bash
alembic upgrade head
```

### 6. Запуск веб-приложения
```bash
uvicorn app.main:app --reload --port 8000
```
После запуска откройте браузер по адресу: **`http://localhost:8000`**

Документация Swagger/OpenAPI доступна по адресу: **`http://localhost:8000/docs`**
